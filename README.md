# EDS223 HW2: Exploring patterns of environmental justice

## Description

This repository contains files related to the HW2 assignment "Exploring patterns of environmental justice" for EDS223, part of the UCSB MEDS 2027 graduate program. In this assignment, we explored the following:

- Part 1: Legacy of redlining in current environmental (in)justice
- Part 2: Legacy of redlining in pedstrian and bike accidents

The below directory tree maps out the layout of this repository:

```
EDS223-HW2
└───.gitignore
│   └───data
│       ├── ejscreen
│       ├── mapping-inequality
│       └── SWITRS_LA
├── HW2.pdf
├── HW2.qmd
└── README.md
```

## Data

The data used for this assignment is from the EJScreen: Environmental Justice Screening and Mapping Tool, which no longer exists online. However, our data can be accessed through the following link: [https://drive.google.com/file/d/1nG6Nj1bXfzQFOVMO8Km3eNy4SWu1YcIQ/view](https://drive.google.com/file/d/1nG6Nj1bXfzQFOVMO8Km3eNy4SWu1YcIQ/view)
